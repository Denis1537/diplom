# Кулинарная книга (Django)

Простой сайт-книга рецептов на Django с тёмной минималистичной темой, пользовательскими аккаунтами, комментариями, избранным и удобной админкой.

## Стек

- Python 3.10+
- Django 5.x
- SQLite
- HTML + CSS (тёмная тема)

## Установка и запуск

1. Клонируйте (или скопируйте) проект и перейдите в папку:

```bash
cd 300
```

2. (Рекомендуется) Создайте виртуальное окружение и активируйте его:

```bash
python -m venv venv
venv\Scripts\activate      # Windows
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

> Важно: для работы поля `ImageField` нужен пакет Pillow (уже добавлен в `requirements.txt`).

4. Выполните миграции базы данных:

```bash
python manage.py migrate
```

5. Создайте суперпользователя для входа в админку:

```bash
python manage.py createsuperuser
```

6. Запустите сервер разработки:

```bash
python manage.py runserver
```

7. Откройте в браузере:

- Сайт: `http://127.0.0.1:8000/`
- Админка: `http://127.0.0.1:8000/admin/`

## Основные возможности

- Публичная часть:
  - Главная страница с блоками «Сезонные рецепты» и «Последние рецепты».
  - Меню категорий (заводятся через модель `Category`).
  - Список рецептов по категории и страница отдельного рецепта.

- Пользователи:
  - Регистрация и вход по имени пользователя и паролю.
  - Личный кабинет с выводом собственных рецептов.
  - Добавление рецептов (название, описание, ингредиенты, инструкция, фото, категория, флаг «сезонное»).
  - Комментирование рецептов других пользователей.
  - Система избранного (лайки/закладки) + страница «Мои закладки».

- Админка:
  - Просмотр/редактирование пользователей и рецептов.
  - Поле `is_blocked` у пользователя и actions:
    - «Заблокировать выбранных пользователей».
    - «Разблокировать выбранных пользователей».
  - Заблокированные пользователи:
    - Не могут войти на сайт (проверка в форме логина).
    - Не могут добавлять новые рецепты (проверка во вьюхе создания рецепта).
  - Список рецептов с фильтрами и поиском, action «Удалить выбранные рецепты».

## Структура

- `cookbook/` — настройки Django-проекта.
- `recipes/` — приложение рецептов (модели, вьюхи, формы, админка).
- `users/` — приложение пользователей (кастомная модель `User`, аутентификация, профиль).
- `templates/` — HTML-шаблоны (общий `base.html` и страницы приложений).
- `static/css/style.css` — тёмная минималистичная тема.
